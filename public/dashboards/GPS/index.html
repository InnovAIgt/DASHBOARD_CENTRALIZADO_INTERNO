Herramienta de comparación

Comparación GPS Vehículos

Compara tiempos de vehículo y conductor mediante un archivo Excel.

Sin datos cargados

Para comenzar, importa un archivo Excel (.xlsx / .xls) con la estructura de Comparación Vehículos. El archivo debe contener una única hoja con las columnas FECHA, VEHICULO, CONDUCTOR, AREA, UID VEHICULO, UID CONDUCTOR, HORA INICIO RUTA, HORA FINAL RUTA, TIEMPO RUTA, TIEMPO GPS VEHICULO, TIEMPO GPS CONDUCTOR, DIFERENCIA VEHICULO VS CONDUCTOR, ESTADO COMPARACION.

Nota: los tiempos y estados se leen directamente del Excel cargado — el dashboard no recalcula valores. Los tiempos se muestran en formato HH:MM:SS.
